# v0.18.3-profieco.2 — proposed maintenance release

Prepared 2026-11-10; not tagged or published. Based on upstream v0.18.2 and
v0.18.3-profieco.1. Original module paths and MIT notices are preserved.

## Changes

- **Gen1 VU events/faults:** identifiers now use protocol mappings instead of
  protobuf enum numbers. Normalized JSON event, fault and record-purpose labels
  change to their correct meanings, including overspeed protocol byte `0x07`.
  Unknown identifiers remain explicit and round-trip byte-for-byte. Invalid
  semantic enum values now produce encoding errors instead of silently writing
  zero. Gen2 decoding and its existing goldens are unchanged.
- **RecordArray bounds:** offsets, headers and declared spans are checked before
  multiplication, allocation or slicing, including on 32-bit targets. Truncated
  arrays and nonzero counts with zero record size produce parsing errors.
  Zero-count placeholders remain structurally readable; this does not make them
  valid signatures. Valid binary representations remain unchanged.
- **Cyclic driver activities:** wrapped headers now yield previously omitted
  records; invalid record lengths return errors. Exactly 5,000 completed records
  no longer incorrectly trigger the safety limit. The 5,000-record cap remains.
  Tests cover wraparound, empty buffers, invalid indexes, chronological ordering,
  raw-byte round trips and input integrity.
- The CONTROL_CARD owner identification fix remains covered across decoding,
  encoding, formatting and Gen1/Gen2 VU callers.

Independent implementation commits: `97deac8` (#42), `b4b03ab` (#23),
`4867ed4` (#26 and reproduced boundary defects). Assessment: `40e6381` (#39).
No unrelated PR was merged, no binary preprocessing was introduced, and no
original downloads or proprietary fixtures were changed or committed.

## Limitations and publication gate

**Ready as a parser maintenance release with these disclosed limitations.** No
tag or release has been published. Gen2 VU authentication remains unrepaired.

Issue #39 assessment is complete, but wrapper, Overview signed-range and
TechnicalData framing repairs remain pending. Synthetic crypto diagnostics
reproduced the defects without changing authentication code. Complete positive
signed Gen2 VU fixtures and a matching trusted chain are unavailable; see the
[assessment and isolated implementation plan](../gen2-vu-signature-assessment.md).
Invalid signatures continue to fail verification.

Full-file tests skip without proprietary downloads; Gen2 V1 record-golden tests
skip without fixtures. Three ECC chain tests skip without ERCA certificate
`18250066869740371713.bin`. The [maintenance baseline](../profitach-maintenance.md)
lists the exact skipped tests. Synthetic tests do not establish real-device
interoperability or end-to-end trusted authentication. Keep original signed
downloads intact and authenticate original raw bytes.
